## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **Single Page Application (SPA)** responsiva que funciona como um **Currículo Vitae Digital**. O objetivo principal é aplicar e consolidar os conceitos fundamentais de navegação assíncrona no lado do cliente (*client-side routing* e gestão de estado reativo) sem necessidade de recarregamento da página (*full page reload*).

O projeto foi desenvolvido no âmbito da **Tarefa 2.2** da Unidade Curricular de Programação Web Avançada.

---

## 🚀 Funcionalidades

- **Navegação SPA Fluida:** Alternância instantânea entre secções através do controlo de estado reativo do Vue.js 3.
- **Secção "Quem Sou Eu?":** Apresentação do perfil profissional, biografia e avatar.
- **Secção "O que faço?":** Apresentação das competências técnicas com barras de progresso dinâmicas.
- **Secção "Hobbies":** Cartões interativos de interesses pessoais com abertura de janelas modais para detalhes adicionais.
- **Identidade Virtual no Rodapé:** Rodapé com ligações diretas para redes sociais e contactos (LinkedIn, GitHub, Twitter/X, Facebook e Email) utilizando ícones da biblioteca FontAwesome.
- **Design Responsivo:** Adaptado a diferentes tamanhos de ecrã (Desktop, Tablet e Mobile).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização moderna utilizando Flexbox, Grid, Variáveis CSS e transições/animações de estado.
- **Vue.js 3 (via CDN):** Framework JavaScript progressiva para gestão do estado reativo da SPA e renderização condicional (, , eventos).
- **FontAwesome 6 (via CDN):** Biblioteca de ícones para a identidade virtual e elementos visuais da interface.
- **Google Fonts (Inter):** Tipografia moderna e legível.
